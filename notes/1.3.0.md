## What's new

### H3 Studio — official-guide prompts now read properly
So if you write your prompt the way the official MiniMax guide does, with raw `<Picture 1>` / `<Video 1>` / `<Audio 1>` tags instead of `@image1`, it always worked on the model side. The node just didn't know. Every slot went amber with "never mentioned", which was a lie.

Now:
- Raw tags count as mentions. The chip lights up, no more fake warnings.
- They get coloured in the prompt like an `@tag`. Amber with a dotted underline if they point at nothing.
- The "sent to the encoder as" strip tells you when a raw tag points past your filled slots, or when it's written in a form the encoder won't read (`<picture 1>`, `<Picture0>`...).

Careful with raw tags though — the node doesn't renumber them for you. They count filled slots only, images first, then videos, then audio, and a video with "send its sound too" ticked takes its own `<Audio>` number. If you leave a gap in the image rack, your `<Picture 3>` is not image slot 3 anymore. That's exactly why the `@` tokens exist, so use them if you can.

- Carry look mode no longer adds its own instruction line when you already wrote the slot's raw `<Video k>` tag yourself. Your prompt wins over the mode, same as with `@video`.

### Glide DLSS5 Batch (new node)
Point it at a folder and it upscales the clips one after the other. Clips that are already done get skipped, so you can stop it and start again without redoing everything.

### Glide DLSS5
- New `name_from_source` toggle — the output keeps the source clip's name instead of a timestamp. If the name is already taken it adds a number instead of overwriting anything.
