# CGlide 1.2.8

Patch release. One file changed, no behaviour change.

## Fixed

- `csglide_ffmpeg_check.py` used `__import__("sys")` to reach `sys.path`
  instead of importing the module normally. It works identically either way,
  but writing it that way matches a scanner pattern for import evasion, which
  is a fair thing for a scanner to look for. Replaced with a plain
  `import sys`.

Nothing else changed. The diagnostic script behaves exactly as it did in
1.2.7, and no node was touched.
