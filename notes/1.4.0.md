## 1.4.0 · Song mode, timeline audio, and a lot of polish

The big one: H3 can now keep **your real song** instead of re-singing it. Lock a track, lay out the clips, render the whole chain, and the music runs through every join untouched.

### New

- **Song mode in H3 Studio.** Project menu → **Add song**. The track is held clean in the audio half of the H3 latent, so the picture is generated around the real music. Lip sync, drums, everything lands on the actual song.
- **Lay out clips.** Pick 10, 12 or 15 s and H3 Studio cuts the whole song into linked clips. Each clip knows where it sits in the track, and the last one is shortened to end with the song. The song window shows under LENGTH, with a warning if it runs past the end.
- **Timeline audio.** New **Reference | Timeline** switch on the audio slots. In Timeline mode each audio is placed at a real time in the clip and held, and H3 fills the gaps with its own sound. Drag, trim both edges, nudge with arrow keys, or type at / from / to / length / hold. Playback keeps looping while you adjust, so you can find the spot by ear.
- **Glide Audio Lock**: the same audio hold as a standalone node, for graphs without H3 Studio.
- **Glide Join `locked_audio` input.** H3 Studio now outputs the original samples it locked, and Join lays them back over the decoded audio, so the final file has the real song at full quality, not a VAE round trip. Mismatched sample rates are resampled instead of failing.
- **Clip list switch** in the Project menu. The timeline already shows every clip, so the list can fold away.
- Render button gets a little rocket. Selected clip on the timeline now fills with its own colour. Interlaced H3 STUDIO wordmark. Yes, it matters.

### Changed

- **Seam reference is now OFF by default.** On linked clips that change location, H3 could play the reference tail back over the last ~22 frames, and the next link then continued from the old shot. The guide alone holds the join. Workflows saved before are switched off once; turn it back on in ⚙ if a shot stays in the same place and you want it.
- Adopting a render into CONTINUE FROM reuses the copy already in `input/cglide/` instead of making `_2`, `_3` … `_7` of the same file. Video 3 mirrors the guide's file instead of copying it again.
- Render all records a clip's render however it was queued, including ComfyUI's own Queue button. Before, a clip re-rendered outside Render all kept pointing at its older render, and the next link took the old tail.
- Render all can pick up where it was after you switch workflow tabs, and starts clean (old seam tails and stale CONTINUE FROM cleared, your own video 1/2 left alone).

### Fixed

- New project left the old song on the audio timeline with no way to remove it.
- Continuing from a project saved in its own folder could pick a same-named file from the output root (Glide Video now reports the master's subfolder).
- Node couldn't be shrunk from the corner; the prompt area now gives the height back (classic and Vue frontends).
- **Glide DLSS5:** files over 100 MB failed to drop with "Unexpected token 'M'…". Big files now upload in 8 MB pieces, and real server errors are shown.
- **Glide DLSS5 / Batch:** queued renders accept any folder on disk (e.g. `S:\…`), not just ComfyUI's input/output. Preview still reads from ComfyUI's folders. Drop the file on the node to preview it.
