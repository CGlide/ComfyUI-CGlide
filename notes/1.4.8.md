## Save latent moves to H3 Studio 💾

I lost an upscale because my draft workflow still had save_latent on tail. No .h3full, nothing to upscale, and the refine just gave me noise. So the setting now lives in the project, where you set it once.

**Save latent in the settings wheel**
- New line in H3 Studio's settings: **Save latent: full / tail / off**. Default is **full**.
- full also writes the tail, so latent hold keeps working, and every take can be upscaled later. About 30 MB per clip.
- During the **upscale pass** it saves the **tail** by itself, because that's what the next clip holds on. Nothing to switch between the two workflows anymore.

**Wiring (once per workflow)**
- H3 Studio has a new output at the bottom: `save_latent`. Wire it into Glide Video's new `save_latent_in` input.
- When it's wired, Glide Video's own save_latent widget disappears, so there's only one place to set it. Unplug it and the widget comes back, working like before.
- The new output is added at the end, so nothing gets rewired in your workflows.

**See which clips have a latent**
- A thin pink band (the latent colour) now shows above each clip in the strip, in the ruler:
  - **full band**: a .h3full is saved, so the clip can be upscaled
  - **short band at the end**: tail only (.h3latent), so latent hold works but there's nothing to upscale
  - **no band**: nothing saved next to its draft
- Hover a clip and the tooltip says it too. It updates by itself after each render and after Delete latents.
- If a clip has no render recorded, or its record points at nothing (project saved before rendering, or a project from before 1.4.0), H3 Studio now finds the clip's newest render in the project folder by its name and records it. The band shows up, and the upscale pass and latent hold use that file too. Press Save after to keep it in the project file.

**No more silent noise**
- If a workflow has **Glide Upscale Hold** and the upscale pass box is off, H3 Studio now stops with an error telling you to tick it, instead of handing out an empty latent.
- If the upscale pass is on but the clip has no draft recorded, or no .h3full next to it, you get a clear error too.
- If a latent upscaler takes H3 Studio's latent directly while the pass is off, you get a warning in the console.

**Fix: WAV audio playing at half speed** (thanks @luciasanchez2760)
On ComfyUI installs where torchaudio can't open files anymore (new torchaudio versions need torchcodec), H3 Studio falls back to PyAV. That fallback read WAV files wrong: stereo came in as one long mono track, twice as long, so the song played at half speed and an octave down. MP3 was fine, which is why I never saw it. Fixed, and 24-bit WAV is read at the right volume now too. Same fix in Glide Join, for source videos with PCM or FLAC sound.
