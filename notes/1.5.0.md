## You can see what's happening now 

Long runs used to be a black box. A panel saying "queued, waiting for the render...", and Assemble finishing in silence. This one is mostly about that, plus a pile of fixes from the last week of testing.

**Render panel: live info** 🎬
The panel over H3 Studio during a run got a full redo:
- **Live progress bar:** the node that's working right now and its steps, like `KSampler · step 5 / 8 · 62%`. It comes straight from ComfyUI's own progress events.
- **Queue:** when your prompt is waiting behind others, it says how many are ahead.
- **Clip pips:** one dot per clip in the run. Done ones are lit, the current one pulses. Hover a dot for the clip's name.
- **Times:** elapsed, this clip, average per clip, and time **left**. Time left shows up after the first clip, because it's based on your own finished clips, not a guess.
- **DRAFT / UPSCALE** tag (upscale is orange), and the name of the last file made.
- Press Stop and the panel turns amber, "Stopping after this clip", so you know it heard you.
- The H3 Studio button shows the % too: `Rendering 2/4 · 62%`.

If a progress event gets lost on the way, the render doesn't care. It still finishes the same, you just see less detail for a moment.

**Assemble film: a progress banner on Glide Video** 
While a film is being put together, Glide Video shows an orange "Assembling film" banner over its player: which clip it's on, frames done out of the total, a bar and a %. When it's done it goes green, "Film ready", with the file name and length, then fades out. If it fails it goes red with the first line of the error, and stays until you click it.
It works for both: clicking Assemble, and the automatic assemble at the end of a chained run. It shows on the Glide Video that receives the film.

**Upscale to: one tick, sensible defaults**
- Ticking **Upscale to** with no size set now picks **1080p** and **refine 2x** on all clips.
- It remembers your refine factor for upscale mode. Untick and re-tick, and you get your last choice back (1440p / 3x, say), not the default again.
- Drafts keep their own per-clip refine, untouched.
- **Portrait canvases:** the presets use the short edge, so 1080p on a 9:16 clip gives 1080 wide, not 1080 tall. The size follows each clip's own orientation.

**Scope box: Render and Assemble do the same clips**
- New **Scope** box: all / chain / from / clip. It drives both Render and Assemble, so they always agree on what "the film" is.
- Assemble on "clip" assembles that clip's whole chain, not just the clip.
- Assemble picks the **newest render on disk** for each clip (draft or upscale, depending on the pass), unless you picked a take by hand in Takes.
- It also runs by itself after a one-clip render when that clip belongs to a chain, so the film stays up to date.
- The size error is readable now: it names only the clips that don't match the rest, and tells you to pick another take or render them again.

**Paste prompts: one text for the whole project** 📋
Project menu → **Paste...**. Paste one block with a `C1`, `C2`... line before each clip's prompt, and each prompt lands on its clip. Write `C3 — the wake` and the clip gets renamed too. If the text has more clips than the project, it asks before adding any.

**Fixes**
- **Zoom mosaic:** zooming in Chrome during a render tiled the screen into a mosaic after an NVIDIA driver update. It was the blur behind the render panel. Gone, the panel has no blur now.
